# Support

For usage questions, open a GitHub Discussion or issue with the browser and version, operating system, whether the page is `http(s)` or `file:///`, the field label and control type, and the reported skipped reason.

Remove names, email addresses, phone numbers, cookies, tokens, screenshots containing personal information, and private recruiting-site data before posting.

FormPilot does not support bypassing CAPTCHA, authentication, paywalls, or anti-automation controls.
