# Security and privacy

Please do not report vulnerabilities publicly. Use a private security advisory if this repository is hosted on GitHub, or contact the maintainers privately.

Never include real resumes, API keys, cookies, access tokens, or personal contact information in issues, pull requests, fixtures, or logs.

The default design keeps resume data in browser local storage. Any future remote model integration must clearly disclose what data leaves the device and require explicit user configuration.

FormPilot requires an explicit user action before filling or submitting a form. CAPTCHA and authentication challenges remain user-controlled.
