# Roadmap

## Near term

- Add a stable adapter interface for custom searchable dropdowns.
- Add fixture-driven browser checks for dynamic recruiting forms.
- Add a side panel review UI for larger forms.

## Later

- Implement LaTeX-to-JSON synchronization for constrained FormPilot commands.
- Add optional local semantic matching for labels that do not share a key.
- Package signed Chrome and Edge builds.

## Out of scope

FormPilot will not bypass CAPTCHA, authentication, paywalls, or a site's anti-automation controls.
