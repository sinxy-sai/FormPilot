# 简历 JSON 格式说明

FormPilot 的输入是**自由格式 JSON**：key 可以用中文、英文、日文、韩文或混合写法，顶层 key 和子字段 key 都会被归一化到内部词表。你不需要改自己的排版习惯，但**按下面的推荐结构写，匹配成功率最高**。

## 推荐结构

```jsonc
{
  "基本信息": {
    "姓名": "张三",
    "性别": "男",                 // 可选
    "出生日期": "2001-03",        // 可选，YYYY-MM 或 YYYY
    "电话区号": "+86",
    "手机号": "13800000000",
    "邮箱": "zhangsan@example.com",
    "证件类型": "中国 - 居民身份证", // 可选
    "证件号": "110101200001011234", // 可选
    "城市": "杭州",
    "工作年限": "应届生"           // 可选
  },
  "求职意向": {                    // 可选
    "期望职位": "后端开发工程师",
    "期望城市": "杭州",
    "求职类型": "校招",
    "到岗时间": "随时到岗"
  },
  "教育经历": [                    // 数组，一条一段学历；只有一个学校也可以写成对象
    {
      "开始时间": "2022-09",
      "结束时间": "2026-06",        // 在读写 "至今"
      "培养方式": "统招全日制",
      "学校": "云岭科技大学",
      "学历": "本科",
      "学院": "信息工程学院",
      "专业": "人工智能与数据工程",
      "GPA": "3.7/4.0"             // 可选
    }
  ],
  "工作经历": [                    // 数组；没有就给 []
    { "公司": "某公司", "职位": "后端工程师", "部门": "", "开始时间": "2026-07", "结束时间": "至今", "描述": "……" }
  ],
  "实习经历": [
    { "公司": "某科技", "职位": "后端实习生", "部门": "平台研发部", "开始时间": "2025-06", "结束时间": "2025-09", "描述": "……" }
  ],
  "项目经历": [
    { "名称": "项目名", "角色": "个人开发", "开始时间": "2025-03", "结束时间": "至今", "链接": "https://…", "描述": "……" }

  "社交账号": [
    { "平台": "Github", "账号": "https://github.com/xxx" }
  ]

```

## 日期写法

以下都能识别，会被统一成 `YYYY-MM`：

- `2022-09`、`2022/9`、`2022.09`、`2022年9月`
- `2022`（只到年）
- `至今`、`今`、`现在`、`目前`、`present`、`now`、`current` → 标记为「至今」

## 写作建议

1. **重复区块用数组**：教育/工作/实习/项目/竞赛/语言/社交都建议数组，即使只有一条。写成对象也能识别，但数组语义更明确。
2. **一条经历一个对象**。不要把两段实习写进同一个 `描述`。
3. **描述里的换行用 `\n`**，长文本会整体填进 textarea。
4. **没有的区块写 `[]`**（或直接省略）。`"实习经历": {"有实习经历": "是"}` 这种只有开关没有明细的写法，不会生成可填内容，UI 会提示你补充。
5. 不认识的 key 不会报错，会出现在「未识别字段」列表里，方便你自己检查拼写。

## 注意

- `examples/resume.json` 是**演示数据**（虚构人物「林知远」）。如果你拿它去填，会覆盖成演示人物信息 —— 现在 FormPilot 在填写前会自动备份页面当前简历，并可一键恢复，但请务必用你自己的数据文件。
- 你自己的真实简历请放在仓库之外，不要提交进版本库；`examples/` 下带个人信息的备份文件已被 `.gitignore` 排除。
