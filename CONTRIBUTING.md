# Contributing to FormPilot

Thanks for helping improve FormPilot.

## Before opening an issue

- Search existing issues.
- Include the browser, operating system, page type, and affected control type.
- Remove personal information, session tokens, cookies, and private resume content from examples.

## Pull requests

1. Keep changes focused.
2. Add or update tests for matching, parsing, or runtime behavior.
3. Do not add code that bypasses CAPTCHA, login verification, paywalls, or anti-automation controls.
4. Explain any new browser permissions or data transmission.
5. Run the test and syntax-check commands from the README.
