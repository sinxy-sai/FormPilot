# Governance

FormPilot is maintained as a small, maintainer-led open-source project.

- Anyone may open an issue, propose documentation, add a fixture, or submit a pull request.
- Changes should explain user-facing behavior, privacy impact, and verification performed.
- Features that add browser permissions, transmit resume data, or interact with site authentication require explicit design discussion.
- The maintainer reviews pull requests for correctness, privacy, accessibility, and scope.
- Releases are cut from reviewed commits on the default branch.
