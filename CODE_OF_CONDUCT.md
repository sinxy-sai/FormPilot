# Code of Conduct

FormPilot is a learning and open-source project. Participants are expected to be respectful, specific, and constructive.

Unacceptable behavior includes harassment, discrimination, threats, doxxing, unwanted solicitation, and sharing another person's private resume or account data.

Maintainers may remove comments, close issues, or restrict participation when behavior harms the project community. Report conduct concerns privately to the maintainers listed in the repository hosting settings.
